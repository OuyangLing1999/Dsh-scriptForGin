# Dsh-scriptForGin

面向 **DeepSeek Harness (DSH)** 的图形化 Web GUI 插件：为 **60 岁以上老年观众**创作和优化**直播间连麦剧本**，以及**家庭伦理短视频拍摄稿**的扒片与高保真改编。

给不熟悉 AI agent 的人用：填好表单、点一下按钮，剩下的交给 AI。

## 功能

- **项目化工作台**：每个剧本是一个项目，包含创作资料、人物卡、优秀样稿库和成稿版本，自动保存在当前浏览器
- **四种模式**：直播创作、直播优化、短视频扒片、高保真改编
- **创作确认卡**：关系、冲突、目标、结尾、锁定事实与保护台词；也可一键生成全文
- **面板内结果**：任务进度和最终成稿直接在插件面板显示，版本可切换、对照、编辑、导出
- **检查与定向返修**：程序检查字数、交接、栏目、时长与连续性；发现问题可自动定向返修一次，也可按指定要求返修或 AI 审稿
- **分阶段创作**：大纲 → 全文 → 修订 → 审稿；优化分轻度润色 / 结构优化 / 深度重写
- **文件导入**：TXT / Markdown / 字幕 / DOCX；导出 Markdown、TXT 与 DOCX
- **自动更新提醒**：打开面板检查新版，面板内提示，由用户决定是否更新

## 剧本规范（内置在随包 Skill 与任务规则中）

- 线下主播 + 线上连麦（一麦、二麦），一切互动靠台词，不写动作描写
- 单段台词不少于 200 字，一个核心意思说完再交接
- 话轮交接必须显式：点名 / 称呼 / 复述对方观点 / 直接接话
- 主题聚焦孝道、家庭伦理；语言通俗直白，关键信息换说法重复
- 短视频稿按八段式拍摄稿协议：证据表、结构指纹、逐场 11 字段、空间连续性、时长核算

## 安装

在 DSH 的 Agent 会话中执行：

```text
plugin_manager(action: install_bundle, target: <本仓库本地路径>)
```

或使用 DSH Web GUI 的「插件」页面安装本目录，安装后刷新页面。发布 ZIP 内置依赖，解压安装无需额外配置。配套 skill 已随包提供，路径见 `skills/`。

## 使用

1. 打开 DSH Web GUI，点击左侧栏「剧本工具」图标
2. 选择或新建项目，填写主题、模式、原稿或素材
3. 核对「创作确认卡」（或直接一键生成全文）
4. 在「结果与版本」里查看、检查、返修、对照与导出
5. 人物卡和优秀样稿在「人物与样稿」中维护，随项目复用

## 检查更新与发布

面板打开时自动检查 GitHub 最新正式版，保持打开时每 30 分钟重查，离开面板后停止。有新版时，顶部显示更新提醒、可展开的更新说明和「查看并下载更新」入口；用户可选择「稍后再说」，继续创作。底部保留当前版本和手动「检查更新」。自动检查失败会在底部提示原因，并在下一周期重试。所有下载安装由用户主动决定。

面板底部显示当前版本，点击「检查更新」会查询本仓库最新 GitHub 正式 Release，显示新版本、更新说明和下载入口。请求超时或受 GitHub 限流时可重试，不会将失败误报为已是最新版。下载 ZIP 后解压，通过 DSH 插件管理安装解压目录并刷新页面；该按钮不会自动替换插件文件。

每次版本更新都同步到 GitHub：修改 package.json 版本并填写 RELEASE_NOTES.md 后运行 `node scripts/release.mjs`，自动同步界面版本、运行检查、提交代码、推送 main 与版本标签，并上传 ZIP 到 GitHub Release。需要本机 Git、已登录的 gh CLI 和可用的 GitHub 网络连接。仅检查使用 `node scripts/release.mjs --check`。
