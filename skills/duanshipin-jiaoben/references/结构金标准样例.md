# 结构金标准样例

本页定义“成品应具体到什么程度”，不提供可照搬的故事。下方门槛场次是家庭剧情可选分支示例，仅在选中相关题材或原片有对应结构时使用。知识、幽默、退休或旅行题材照样交付八段11字段，但场次功能可为解释、演示、包袱回收或过程收获，不要求记者、认亲、豪门、关系冲突或追更。

## 合格成品的纵向颗粒度

1. 标题先写本集任务与目标时长，不用营销标题代替剧情任务。
2. 拍摄前必看把设备、画幅、收音、光线、自然手持、空间和安全说清。
3. 准备清单不仅列物件，还说明摆放、持有人、首次出现点和剧情功能。
4. 表演规则逐人写目标、动作、节奏、情绪上限、称呼与禁演，不只写性格。
5. 逐场从位置开始，写到镜头、动作、台词、花字、声音、沉默、剪辑和本场功能。
6. “爆点与伏笔”按题材说明重点、依据、包袱或过程结果的回收；家庭剧情可说明关系问题，没有伏笔或追更写“不适用”。
7. 后期与发布建议有时长预算、保留点、字幕/BGM边界、封面标题和自然争议。
8. 验收表让现场能逐项判断是否拍到、是否连续、是否能剪。

## 抽象场次示例

```text
【场 2：第一道空间门槛 / 35 秒 / 把“想见人”升级成“必须证明有资格见”】
位置：院门外；门初始关闭，镜头和人物都不越线。
出场人物：诉求者、守门者、同行者。
空间动作：诉求者和同行者停在院门外；守门者开门一条缝但不让路；本场结束无人跨过门槛。
镜头怎么拍：中景跟诉求者走到门前；切手部按铃；回到双人中景等待；门只开一条缝后才出现守门者。
人物动作：诉求者先按铃并退半步；守门者只露上身，不主动让路；同行者在对话第三轮才出示已确认的证明。
台词：每轮短句。第一轮问来意，第二轮质疑关系，第三轮提高证明门槛；不得加入证据表中没有的姓名或材料。
屏幕花字：首轮出现核心关系词；不写煽动性结论。
环境音 / BGM：保留门铃、脚步和开锁声；此场不用 BGM。
沉默和停留时间：守门者看到证明后停 2 秒，让态度变化可见。
剪辑注意事项：开门前不能切门内反应；保留开锁声和守门者让出半步的动作。
本场功能：把“想见人”升级成“必须证明有资格见”，建立第一道行动与关系门槛。
```

该示例展示的是“指令可执行 + 空间连续 + 功能明确”，不是要求每条视频都用院门、证明或三轮对话。

## 真实感替换原则

- 使用自然手持：跟随动作时有轻微呼吸感，关键证据出现时保持可辨认；不故意剧烈晃动。
- 使用生活痕迹：只保留与人物状态和空间可信度有关的陈设，不按清单人为做旧。
- 使用真实反应：允许停顿和儿童自然行为，但每段都说明可剪边界；不把笑场、口误和失控当必需品。
- 使用透明运营：列出剧情天然产生的争议与官方置顶评论建议，不生成假账号评论。

## 不合格降级

以下任何一种都未达到金标准：只有剧情梗概；只有台词没有镜头/动作；准备清单与剧情无关；场次没有时间预算；门和人物突然跳空间；把推断写成事实；把具体样本道具当公式；发布建议包含虚假互动操作。
