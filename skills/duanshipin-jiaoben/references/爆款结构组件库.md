# 爆款结构组件库

把组件按“功能”迁移，不照抄样本人物、豪门、记者或道具。

## 开场钩子

首屏先识别核心亲缘/伦理关系，并给出结果期待：可以是行动目标、已被打破的承诺，或尚未解释的巨大损失。关系先行不等于没有悬念，悬念可转为“如何得到、为何失去、要付什么代价”。

## 人物功能位

- 诉求者：承担单一、可复述的本集目标。
- 缺席/延迟目标：被反复谈论，出现或回应即构成回报。
- 门槛守卫者：控制空间、信息、资源或接触权。
- 可争取决策者：态度变化形成阶段奖励。
- 怀疑派与辩护派：分别承担清楚的观众立场；非必要不扩角色。
- 儿童/依赖者：关系核心、视觉证据或行动触发者，不是台词工具。
- 观众：告白型单集中可被设为倾诉与判断对象。

## 阻力与证据阶梯

事件集的阻力每轮必须加价或换形：拒绝行动 → 质疑身份 → 提高证明门槛 → 限制关系 → 增加现实代价。守门人可更换，阻力不能只是同义争吵。

证据从弱到强布置：持续行动、具体照料、可见相似/旧物、拒绝不当利益、可核验材料、目标人物确认。证据强度不得超过已知事实；扒片时还要保持材料的原始状态，不能把口头承诺升级成实物在场、当场出示或已经核验。生活照料清单只有在证明长期照护能力或抬高分离成本时才保留。

角色告白集无现场对手时，用因果揭露和代价升级替代：关系建立 → 误解/选择 → 不可逆后果 → 当下困境 → 残酷选择。只有情绪形容而无新因果属于纯重复。

## 空间推进

门外、院内、楼门、客厅等空间门槛可视化家庭准入和权力变化。单场景也能成立，但每一段必须改变阵营、证据、帮助程度或因果理解。空间严格按真实开闭和进入顺序。

## 四类阶段奖励

1. **得到型**：相认、拥抱、获准见面。
2. **失去型**：交出孩子、被迫离开、关系被切断。
3. **部分接纳型**：获准进门、被相信、留下联系方式、获得临时帮助。
4. **解释型**：回收开头损失，补齐前史并完成动机辩护。

兑现后可留人物反应供情绪消费，但长度服从实际表演与时长预算，不把所有拖尾视为有效。

## 追更债务

结尾留下已建立但未解决的具体关系问题：缺席者何时回应、身份如何核验、照护责任归谁、阶段接纳是否反转。可以不用口播“下集见”；固定人物旧账、状态损失和主目标前进一步都能形成追更。

## 自然争议

从剧情事实提炼两种以上可辩护立场，例如责任与边界、动机与证据、亲权与照护。家庭议事厅可让角色承担不同判断。只输出争议问题和官方账号可透明表达的立场，不伪造评论。
