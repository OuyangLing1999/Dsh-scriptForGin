# 工具启动条件

## 默认路径

原生视频理解优先。当前多模态模型直接联合读取画面、音轨、字幕和时间关系，默认不调用 FFmpeg、ffprobe、拆帧、音频提取、OCR 或 Whisper。工具不是“更专业”的固定步骤，而是特定精度或可读性问题的备用取证路径。

## 允许启动

满足任一项才启动：

1. 用户明确要求转字幕、拆帧、精确时间轴、工具分析或工具复核；
2. 当前模型无法读取视频、画面或音轨；
3. 人名、金额、日期、亲属关系等关键事实不确定；
4. 关键台词的不同听法会改变剧情因果；
5. 画面字幕与声音内容冲突；
6. 用户要求逐字字幕、精确到秒的镜头长度或可审计证据。

普通语气词、无关口误、口音细节和不影响剧情的小误差不触发工具。

## 最小范围原则

先记录需要回答的精确问题、对应大致时间段和所需证据类型。能局部复核就只截对应片段/帧/音频，不默认全片拆帧或双模型转写。输出中区分原生观察、工具证据和仍未确认项。

备用脚本 `scripts/extract_video_evidence.py` 只能由用户要求或上述条件显式触发；不得在 Skill 启动、视频上传或扒片模式中自动运行。

## 失败处理

- 无法读取：说明具体失败点，再尝试最小备用路径。
- 工具不可用：报告依赖/格式问题，不能假装已复核。
- 多源冲突：保留冲突，优先可见原始证据；影响因果且无法裁决时向用户确认，不能留给拍摄现场猜测。
- 工具结果只用于补证，不取代对动作、表情、空间、沉默和环境声的联合理解。
