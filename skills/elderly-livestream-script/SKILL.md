# 老年观众直播间剧本创作规范（连麦型）

## 适用场景
为 60 岁以上老年观众创作直播间剧本，含线下现场与线上连麦（一麦、二麦）结构。

## 一、场景与角色
- 线下：直播间现场出现的人（含主播），观众可见。
- 线上：一麦、二麦等连麦人员。观众看不到其肢体动作，一切信息只能靠台词传递。
- 角色卡：动笔前先给每个角色固定三要素——称呼、身份/立场、说话风格。
- 全剧本不写动作、神态、舞台提示；互动、情绪、反应全部通过对白体现。连麦方发生的事（惊讶、犹豫、转身拿东西）必须"说"出来，不能只"演"出来。

## 二、对白规则
- 单段台词不少于 200 字；说完一个完整意思，再明确交给下一个人。
- 一段内部结构：观点 → 生活例子/亲身经历 → 情感落点 → 交接语。
- 每段只表达一个核心意思，不塞多个信息点。
- 段落超过 350 字时，把多余信息拆到下一个话轮，或让对方用短垫话（"是这个理""对呀"）承接后再继续。

## 三、话轮交接规则（必须显式）
交接方式至少用一种，写进台词：
1. 点名/称呼："张姐，您说是不是这个理？"
2. 复述对方观点："您刚说的'儿女再忙也得常回家'，我听着心里就一热……"
3. 直接接话："这话说到我心坎里了……"
4. 提问过渡："那您家孩子是咋做的？"
禁止突然跳转、抢话、没头没尾地换话题。

## 四、主题与情节
- 核心主题：世俗孝道、家庭伦理。
- 可扩展：健康养生、怀旧亲情、子女关怀、邻里互助、节俭过日子、养老陪伴、夫妻相守、防诈骗提醒。
- 减少复杂逻辑与推理：不设悬疑、反转、双关、伏笔；一件事顺着讲完。
- 情节三件套：生活化场景 + 具体小事 + 情感共鸣。每幕至少一个老人熟悉的生活细节。

## 五、语言与节奏
- 通俗直白，全口语；多用短句，少用长定语。
- 不用网络流行语、谐音梗、缩写、中英夹杂。
- 语速节奏慢：关键信息换说法重复至少 2 遍（如活动规则、价格、时间、子女话题落点）。
- 数字、时间、金额用大白话再说一遍（"晚上八点，就是吃完晚饭那个点"）。

## 六、剧本输出格式
只输出两种行：
- 角色行：`【角色名】`
- 台词行：纯对白段落
不写"（笑）""（停顿）""镜头切……"等任何提示。

示例：
【主播】
张姐，今天直播间里这么多叔叔阿姨都在说，孩子工作忙，一个月也回不了一趟家，我听着心里也挺不是滋味。您说咱们当爹妈的，这一辈子图的是啥？不就是图孩子平平安安、健健康康的，有空了能回来坐坐，一家人围在一块吃顿热乎饭嘛。钱多钱少，够用就行，可心里头这份惦记，那是多少钱都买不来的。好多叔叔阿姨跟我说，晚上睡不着的时候，就爱翻翻孩子的照片，越看越想，越看越睡不着。所以今天我把李姐也请上来了，李姐她家孩子就在外地工作，一年到头也就过年回来一趟，她最有体会。李姐，您跟大伙儿说说，是不是这么个理儿？

## 七、创作流程
1. 定主题（从主题清单选一个）；
2. 定角色卡（主播 + 一麦 + 二麦，各自身份立场）；
3. 列信息点（活动/商品/观点，每个信息点准备两种说法）；
4. 分幕：开场问好 → 引出话题 → 一麦讲述 → 二麦补充/不同视角 → 主播收口点题；
5. 按格式写对白；
6. 用自检清单过一遍。

## 八、自检清单（交付前逐项核对）
- [ ] 全篇无动作/神态/舞台提示
- [ ] 每段正式台词 ≥200 字
- [ ] 每次换人都有点名/称呼/复述/接话等显式过渡
- [ ] 每段只讲一个核心意思
- [ ] 无网络流行语、无谐音梗、无复杂句式
- [ ] 关键信息至少换说法重复 2 遍
- [ ] 无悬疑、反转、双关、伏笔
- [ ] 有一个老人熟悉的生活细节
